# 📊 E-commerce Order Analysis

## 📌 Project Overview

This project analyzes e-commerce order data to extract meaningful business insights using Excel.

## 📂 Dataset

* 1200+ rows of order data
* Includes order status, revenue, product details, and payment methods

## 🛠 Tools Used

* Microsoft Excel
* Pivot Tables
* Data Cleaning
* Data Visualization

## 📊 Analysis Performed

* Order Status Distribution (%)
* Revenue by Order Status

## 💡 Key Insights

* Cancelled orders are the highest (~20.8%), indicating potential issues
* Revenue is distributed almost evenly across all order statuses
